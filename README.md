# linux_project1
Linux web server deployment and administration

Project Overview

Implemented a Linux Web Server Deployment and Administration project to understand Linux server management, user administration, file permissions, storage management, backup and security.

Objectives

- Manage Linux users and groups.
- Configure file permissions and ownership.
- Perform file and directory management.
- Create backups using tar.
- Implement basic Linux server security.
- Monitor and troubleshoot server activities.

Tools Used

- Ubuntu Linux
- Linux Commands
- Bash Shell
- SSH
- tar

Implementation Steps

1. Created and managed Linux users and groups.
2. Configured file permissions and ownership.
3. Performed file and directory management.
4. Managed disk storage and partitions.
5. Created compressed backups using "tar".
6. Performed basic Linux server security and administration tasks.

Key Learnings

- Gained practical experience with Linux commands.
- Understood Linux user and group management.
- Learned file permissions and ownership.
- Practiced backup and restore operations.
- Improved Linux server administration and troubleshooting skills.


Conclusion

Successfully completed hands-on Linux server administration tasks and gained practical knowledge of Linux system management, backup operations, file management and basic server security.
